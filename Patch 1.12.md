
# Portugal 1111: A Conquista de Soure — Actualização 1.12

A patch 1.12 pode ser descarregada em: [Patch 1.12](https://web.archive.org/web/20040727155259/http://www.portugal1111.com/patchs/patch1_12.zip)

Esta patch corrige ou adiciona as seguintes situações:

## 31/05/2004 — PATCH 1.12

- Unidades ficam com a moral baixa depois de "saltarem" para um novo mapa.

## 26/05/2004 — PATCH 1.11

- Gravar o estado PARAR.
- Gravar as selecções (1-9).
- Problema da gravação do jogo no lado mouro.
- Música por defeito baixa.
- Disparo das torres reduzido para metade.
- Velocidade de Onager e Trabuco diminuída.
- Correcção do nome "Mulher" para "Camponesa"
- Utilizar setas para diagonais.
- Informação de unidades disponíveis em um talhão de trigo.
- Quando termina o vídeo inicial passa automaticamente para o jogo.
- Símbolo "zero" e "vazio" equivalentes.
- Tecla ESC para menu.
- Usar CRTL + A para tornar edifícios transparentes. Permitir visualizar unidades escondidas.
- Usar CRTL + botão esq. rato ou botão central do rato para mover o mapa lentamente.
- Tempos do símbolo "frequência" alterados. Este símbolo deve ser usado  para criar acções não repetitivas. Usar por exemplo nos trombeteiros.
- Fundo do minimap alterado.
- Optimização geral do motor do jogo. Esta alteração tem grande impacto em mapas que utilizem muralhas ou caminhos  bloqueados. Resolve também várias situações a partir do mapa 5 da campanha.
